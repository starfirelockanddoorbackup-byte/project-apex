## Overview

**Project APEX** is an off-grid, EMP-hardened computing vault and autonomous neural oracle designed for local governance, critical civil utilities, and emergency responders. Built to address the systemic vulnerabilities of centralized cloud computing and fragile regional grids, APEX ensures that when wide-area communications and supply chains fail, municipal decision-making, water treatment telemetry, emergency medicine, and tactical dispatch survive.

---

## Core Capabilities

- **100% EMP/CME Hardened:** MIL-STD-188-125 compliant shielding with continuous beryllium-copper gaskets and sub-nanosecond surge arrestor arrays.
- **Zero External Grid Demand:** Dedicated DC microgrid interface buffered by long-cycle LiFePO4 cells and isolated solar charge controllers.
- **Air-Gapped Neural Oracle:** On-premise, quantized large language model providing sub-15ms local inference without satellite, cellular, or fiber connections.
- **Direct SCADA & Mesh Interfacing:** Offline calculation matrices for water treatment stoichiometry, bio-equivalent pharmaceuticals, priority load shedding, and digital packet radio dispatch (AX.25 / LoRa).

### Deploying via GitHub Pages

1. Fork or clone this repository.
2. Ensure the primary presentation file is named `index.html` in the root directory.
3. In your repository, navigate to **Settings > Pages**.
4. Under **Build and deployment > Branch**, select `main` (or `master`) and `/ (root)`.
5. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within 1–2 minutes.
